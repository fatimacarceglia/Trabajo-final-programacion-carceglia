Para poder utilizar el proyecto es necesario tener instalado XAMPP.
El proyecto debe estar dentro de la carpeta htdocs de XAMPP.
Una vez hecho esto, hay que abrir XAMPP y activar Apache y MySQL.
Después, ingresar a phpMyAdmin desde el navegador, importar el archivo database.sql y esperar a que se cree la base de datos.
Por último, abrir el navegador y entrar a la siguiente dirección:
http://localhost/refugio_animales/
se debe tener conexion a internet ya que las imagenes fueron sacadas de este mismo
